# Typing-Tester
A simple and interactive Typing Speed Tester built with HTML ,CSS and JavaScript. Test your typing speed , accuracy and performance while typing randomly selected paragraphs.
# Features
- Countdown Timer
- Real-time typing test
- Words Per Minute (WPM)
- Typing accuracy tracking
- Mistake counting 
- Correct character Highlighted
- Try Again option
# Technologies Used
- HTML
- CSS
- JavaScript
# How to use 
- Open the typing Tester .
- Read the paragraph 
- Start typing 
- Your performance is calculated while you type
- When the test finishes , check your typing results
- Click Try Again to start a new test
